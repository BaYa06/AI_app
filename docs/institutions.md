# Как подключить учебный центр

Центр получает свои книги во Flashly. Их видят только его ученики (по коду) и его учителя.
Центр выпускает коды и смотрит цифры в кабинете `flashlycards.app/center`. Имён учеников
кабинет не показывает. План и правила — `plan/new/center_books.md`.

## Перед первым центром на проде

- Миграция 052 (`database/migrations/052_center_books.sql`) применена к прод-базе, а API с
  книгами центра выкачен на прод (ветка `main`). Без этого коды и кабинет не работают.
- Вход по почте и паролю в Supabase включён (Authentication → Providers → Email). Он нужен
  только кабинету: в приложении входа по паролю нет, поэтому аккаунт центра в приложение не
  попадёт.

## 1. Создать центр и логин

1. Запустить локальную админку: `node admin-server.mjs` (откроется `http://localhost:3001`).
2. Внизу страницы, в блоке «Учебные центры», выбрать базу:
   - **staging** — для проверки, по умолчанию;
   - **прод** — настоящий центр. Каждая запись спросит подтверждение (слово «прод»).
3. Заполнить форму и нажать «Создать центр и логин»:
   - **Название**, **город**;
   - **Логин** — латиница, например `alfa`. Центр входит в кабинет по нему;
   - **Начало кодов** — 3–8 латинских букв и цифр (`ALFA`). Для длинного названия выбрать
     короткое слово: «Международная школа языков Lingua» → `LINGUA`;
   - **Мест по договору** — сколько учеников одновременно могут пользоваться книгами;
   - **Договор до** — после этой даты книги закроются у всех учеников и учителей центра.
4. Админка один раз покажет временный пароль. Нажать «Скопировать» и сохранить: второй раз
   его не показать, только выдать новый.

Логин один на staging и прод (Supabase общий). Если центр с этим логином уже создан в другой
базе, админка возьмёт тот же логин и выдаст новый пароль.

## 2. Загрузить книги центра

Новая книга из Excel (шаблон — `templates/book_template.xlsx`):

```
npx tsx scripts/import-book.ts книга.xlsx --org ALFA --dry-run             # проверка, в базе ничего не меняется
npx tsx scripts/import-book.ts книга.xlsx --org ALFA --publish             # прод
npx tsx scripts/import-book.ts книга.xlsx --org ALFA --publish --staging   # staging
```

`--org` принимает начало кодов (`ALFA`), логин (`alfa`) или id центра. `--publish` открывает
книгу ученикам и учителям центра: без него книга видна только в кабинете с пометкой «Готовится».
В общую библиотеку книга центра не попадает и с `--publish`.

Если такая книга (название + издание) уже есть как общая или книга другого центра, импорт
остановится. Тогда:
- **отдельная копия для центра** — поменять «Издание» (edition) в Excel, например
  `2nd · Alfa`, и загрузить заново;
- **отдать центру саму книгу** — в админке, таблица «Книги: общая или центра», выбрать центр.
  Если книгу уже учат или она подключена к курсам, админка спросит подтверждение: общая
  книга пропадёт из библиотеки у всех, а её ученики без доступа к центру её потеряют
  (прогресс сохранится).

Там же задать **порядок** книг центра внутри языка: 1 — Beginner, 2 — Elementary и т. д.
По нему приложение предлагает «Перейти на следующий уровень».

## 3. Передать доступ центру

Отправить менеджеру центра:

```
Кабинет: https://flashlycards.app/center
Логин: alfa
Пароль: <временный пароль>
```

При первом входе кабинет попросит придумать свой пароль. После этого мы пароль не знаем.

## 4. Что делает центр

1. **Профиль центра**: логотип, приветствие (ученик видит его, когда вводит код) и контакт
   менеджера (ученик видит его, когда доступ кончился).
2. **Коды подключения** → «Выпустить код»: для кого, метка (по умолчанию месяц), до какого
   дня можно ввести, сколько дней доступа, сколько мест по коду. Получается код вида
   `ALFA-DEC-7KXM`, ссылка `flashlycards.app/join/ALFA-DEC-7KXM`, QR и готовый текст для
   WhatsApp.
3. Ученик скачивает Flashly, вводит код («Введи код» при первом запуске или «Ввести код» в
   боковом меню) или открывает ссылку / QR. Дальше выбирает свою книгу → «Добавить книгу»:
   книга целиком становится его курсом в боковом меню (урок дня, разминка, все юниты как обычные
   наборы). Другие книги центра — полкой «Книги <центр>» в «Библиотеке», «Добавить себе».
   Если та же книга подключена в группе учителя — работают оба курса: в группе видны юниты,
   открытые учителем, в личном курсе — все; прогресс общий, место одно.
4. **Обзор**: места, ученики с доступом, кто занимался, слова, по книгам, CSV.
5. **Учителя и группы** (если учителя центра ведут группы во Flashly): «Создать ссылку» →
   отправить учителям `flashlycards.app/t/…`. Учитель открывает ссылку в телефоне, входит и
   нажимает «Стать учителем центра». Книги центра появляются у него в «Библиотеке» отдельной
   полкой; он подключает их к своим группам («Подключить к курсу») и открывает юниты. Ученики
   группы получают открытые юниты без кода и занимают места центра.
   - «Убрать из центра» — книги центра отключаются от групп учителя, группы остаются у него.
   - «Новая ссылка» — старая перестаёт работать (если её переслали не тому).

## 5. Проверить после подключения

- Войти в кабинет под логином центра, выпустить тестовый код на 1 место.
- На тестовом телефоне ввести код: «Центр найден» с логотипом → выбрать книгу → «Добавить
  книгу» → главная на курсе книги, юниты списком.
- В кабинете на «Обзоре» место занято, в «Кодах» у кода 1 активация.
- Выключить тестовый код («Выключить»).

Для проверки на staging: кабинет открывается на preview-адресе ветки `dev` по пути `/center`,
приложение — сборка TestFlight Staging.

## Дальше по ходу работы

| Нужно | Как |
|---|---|
| Центр забыл пароль | Админка → центр → «Новый пароль», передать центру. Старый перестаёт работать |
| Продлить договор, добавить мест, сменить начало кодов | Админка → центр → «Изменить» |
| Новая книга | Шаг 2 |
| Договор не продлили | Ничего делать не нужно: после даты книги закрыты, кабинет — только просмотр. Продлили — доступ возвращается сам, прогресс учеников на месте |

## Частые вопросы центров

- **«Код не находится».** Код выключен, вышел срок «ввести до» или опечатка. В случайном
  хвосте кода нет похожих символов (O, 0, I, 1, L), так что путаница возможна только в начале.
- **«Места кончились».** Заняты все места по договору или по этому коду. Место освобождается,
  когда у ученика кончается доступ. Больше мест — продлеваем договор.
- **«У ученика пропали книги».** Кончился доступ по коду. Новый код прибавит дни к оставшимся,
  прогресс сохранён.
- **«Учитель не может подключить книгу к группе».** Не хватает мест центра для учеников этой
  группы (приложение пишет: нужно N, свободно M) или в группе уже книги другого центра.
- **«Можно увидеть, кто из учеников не занимается?»** Нет: кабинет показывает только числа.
  Имена своих учеников видят учителя в группах приложения.

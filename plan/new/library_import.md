# Импорт наборов библиотеки из Excel

Наполняем библиотеку пачками из Excel так же, как каталог книг (`scripts/import-book.ts`), только
без книг и юнитов: один файл → много наборов → сразу в `library_sets` / `library_cards`.

Шаг = коммит «LibImport N». Отмечать ✅ по мере выполнения.

---

## Решения (02.11.2026)

1. **Вариант A — локальный скрипт.** `npx tsx scripts/import-library.ts file.xlsx [--dry-run] [--publish]`.
   Пишем напрямую в `library_sets` (`original_set_id = NULL`) и `library_cards`. «Мои наборы» админа не трогаем.
2. **Автор — служебный аккаунт «Flashly».** Отдельная строка в `users` с `is_admin = true`, без email
   и без входа: в него никто не залогинится, поэтому его нельзя удалить из приложения
   (`api/data.js` при удалении аккаунта стирает `library_sets` владельца). Это урок 01.11.2026.
3. **Новые категории:** IELTS, История, География, тесты Кыргызстана (ОРТ, НЦТ и подобные).
4. **Минимум 5 карточек** в наборе, как при обычной публикации.
5. **Сначала черновик.** Без `--publish` наборы попадают в базу со статусом `draft` и в библиотеке не видны.
   С `--publish` переходят в `published`.

## Формат Excel

Один файл — сколько угодно наборов. Строка 1 — заголовки, регистр не важен.

**Лист «Наборы»**

| колонка | обяз. | что |
|---|---|---|
| `title` | ✔ | название, ≤ 100 символов; по нему (вместе с языками) набор находится при повторном импорте |
| `category` | ✔ | ключ из списка категорий библиотеки (в шаблоне выпадающий список) |
| `language_from` | ✔ | код языка: en, ru, ky… |
| `language_to` | ✔ | код языка |
| `description` |  | описание |
| `tags` |  | через запятую, например `ОРТ, математика` |
| `cover_emoji` |  | один эмодзи |

**Лист «Карточки»**

| колонка | обяз. | что |
|---|---|---|
| `set` | ✔ | `title` набора с листа «Наборы» |
| `term` | ✔ | лицевая сторона |
| `translation` | ✔ | обратная сторона |
| `example` |  | пример (в базе — `library_cards.hint`) |

Порядок карточек — порядок строк. Проверки до записи в базу: набор из «Карточек» есть в «Наборах»,
нет пустых term/translation, нет дублей term в наборе, категория известна, ≥ 5 карточек.

Предметные наборы (история, география, ОРТ) без перевода: `language_from = language_to`
(`ru`/`ru` или `ky`/`ky`). Фильтр языков в библиотеке сейчас только «иностранный → ru», поэтому
такие наборы видны без фильтра языка. Это нормально, отдельные чипы языков — на потом.

## Повторный импорт

- Набор ищем у служебного автора по `title + language_from + language_to`.
- Метаданные обновляем, карточки **заменяем целиком**. Это безопасно: у пользователей своя копия
  (импорт копирует в их `card_sets`), прогресс к `library_cards` не привязан.
- Лайки, оценки и `imports_count` сохраняются: строка `library_sets` та же.
- Наборы, которых нет в файле, не трогаем, только перечисляем в отчёте.
- `--publish` не возвращает в `published` то, что уже было снято вручную (`archived`). Только `draft → published`.

## Проверка

1. `--dry-run` на шаблоне: отчёт верный, в базе ничего нет.
2. Импорт без `--publish`: в приложении наборов не видно. С `--publish`: видны, автор «Flashly», фильтр по категории работает.
3. Повторный импорт того же файла: «без изменений». Правка карточки в Excel → набор «обновлён», лайки и счётчик импортов на месте.
4. Пользователь импортирует набор IELTS → в «Моих наборах» категория «Учёба».

# Помощь учителю на сайте: flashlycards.app/teachers/help (Help N)

Учитель должен найти ответ за несколько секунд, в том числе с телефона прямо на уроке. Раздел —
короткие ответы, шаги и вертикальные ролики 9:16. Ролики снимаются параллельно
(Notion: «План съёмки вертикальных роликов»), сайт не ждёт их: вопрос без ролика показывается
без блока видео.

Макет (утверждён 21.11.2026): https://claude.ai/artifact/CjBvHuc1tXtJp5ozMMju3a
Если план и макет расходятся, верен план.

Шаг = коммит «Help N». Коммиты — в dev. В main — только с разрешения. **Код — только по команде.**

## Адреса

| Адрес | Страница | Файл |
|---|---|---|
| `/teachers/help` | Хаб: поиск, «Идёт урок?», ролики, «Первые 10 минут», темы, частые вопросы | `public/site/help/index.html` |
| `/teachers/help/c/{тема}` | Тема: список вопросов с раскрывающимися ответами | `public/site/help/c/{тема}.html` |
| `/teachers/help/{slug}` | Вопрос: короткий ответ, «Где», ролик, шаги, «Если не получилось» | `public/site/help/{slug}.html` |
| `/ky/teachers/help/...` | Кыргызская версия (Help 12) | `public/site/ky/help/...` |

Slug — латиница через дефис, по смыслу вопроса: `invite-students`, `student-cant-join`,
`set-not-visible`, `live-test`. Slug не меняется после публикации (на него ведут ссылки из
приложения и роликов). Переименовали — старый slug в `redirects` вопроса.

## Контент — один файл данных

`site/help/content.ru.json`:

```json

  "questions": [{
    "slug": "invite-students",
    "category": "students",
    "question": "Как дать ученикам код курса?",
    "answer": "Главная → «Код курса». Покажите классу 6 цифр или нажмите «Поделиться».",
    "where": ["Главная", "Код курса"],
    "steps": ["…", "…"],
    "tips": ["…"],
    "platform": "На Android и в браузере окно выглядит иначе.",
    "urgent": true,
    "isNew": false,
    "keywords": "код пригласить ссылка qr",

    "screenshots": ["invite-students-1.webp"],
    "related": ["student-cant-join"],
    "updated": "2026-11-21"
  }],
  "home": { "urgent": ["…"], "firstSteps": ["…"], "popular": ["…"] }
}
```

Проверки при сборке (ошибка — сборка падает, как сейчас у `build-site.mjs`):
- slug уникальны, тема существует, в `related` и `home` — существующие slug;
- вопрос заканчивается на «?» (кроме утверждений «Ученик не видит набор»), ответ ≤ 200 символов,
  хотя бы один шаг;
- `title` страницы ≤ 60, `description` ≤ 155 (те же правила, что в `checkRoutes`);
- файл постера и скриншотов существует.

### Как добавить ролик (решение 21.11.2026)

1. Владелец загружает ролик на YouTube (приложение YouTube → «+» → «Видео» или studio.youtube.com;
   вертикальный ролик до 3 минут сам становится Short). Название = вопрос, описание = короткий ответ
   + ссылка на страницу вопроса. Добавить в плейлист «Flashly для учителей».
2. Ссылку — в колонку «Ссылка YouTube» нужной строки базы «Видео — план» в Notion, статус
   «Смонтировано». Обложку (кадр с вопросом из CapCut) — файлом в ту же строку, если есть.
3. Команда «добавь ролики»: читаем Notion, вписываем `youtubeId` (и обложку) в `content.ru.json`,
   коммит «Help video: {slug}» в dev → preview на Vercel. На прод — вместе со следующей выкладкой
   в main. В Notion статус → «На сайте».

Сами видеофайлы в репозиторий и на Vercel не кладём. Нет своей обложки — берём превью YouTube
(`i.ytimg.com/vi/{id}/...`) при сборке и сохраняем WebP в `public/site/help/img/`.

Позже, если роликов станет много: `npm run help:sync` — скрипт читает базу Notion по API
(токен `NOTION_TOKEN` только локально) и сам обновляет `content.ru.json`.

## Чего не делаем

- Отдельного движка (Next.js, Docusaurus) и CMS — хватает JSON + генератора, как у остального сайта.
- Хранения роликов на Vercel — только YouTube.
- Внешнего поиска (Algolia и т.п.) — ~30–50 вопросов ищутся на клиенте.
- Отправки «Помогло?» на свой сервер — только событие аналитики (план `vercel_cpu.md`).
- Вопросов про функции, которых нет на проде.

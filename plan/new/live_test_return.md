# План: вернуться к идущему тесту (учитель вышел на главную)

Источник: вопрос учителя 28.11.2026. Учитель начал тест, вышел на главный экран, тест идёт,
ученики пишут, а вернуться к мониторингу нельзя.

Шаг = коммит `LiveReturn N`. Работаем в `dev`, база — только staging. Новых таблиц и миграций нет.

## Причина

- `LiveTest` (монитор) открывается один раз через `navigation.replace` из `TestLobbyScreen`
  (`TestLobbyScreen.tsx:143`). Других входов нет.
- `getHistory` (`api/_handlers/test/teacher.js:~470`) берёт только `status = 'finished'`,
  поэтому идущий тест в «Истории тестов» не виден.
- На главной и в курсе нет плашки «идёт тест».
- Так же теряется сессия в статусе `waiting` (код выдан, учитель вышел из лобби до старта).

Тест при этом живёт на сервере. Учитель теряет только управление: монитор, «Завершить», пауза,
+время, возврат выбывших.

## Решение

Показывать учителю плашку «Идёт тест — вернуться» везде, где он оказывается после выхода.
Плашка ведёт в нужный экран по статусу сессии:

| статус сессии | куда ведёт |
|---|---|
| `waiting` | `TestLobby` (лобби с кодом) |
| `active` | `LiveTest` (монитор) |

Сервер отдаёт «мои незавершённые сессии», приложение показывает плашку.

## Как проверять

1. Учитель создаёт тест, ученик входит, учитель жмёт «Начать».
2. Учитель выходит на главную: плашка «Идёт тест» видна, счётчик учеников верный.
3. «Вернуться» открывает монитор, данные те же, «Завершить» работает.
4. То же для экзамена (`engine = 2`): пауза и +время доступны.
5. Выйти из лобби до старта: плашка ведёт в лобби с тем же кодом.
6. Завершить тест с другого устройства: плашка исчезает, нажатие по устаревшей плашке открывает итоги.
7. Другой учитель и ученик плашку не видят.

## Чего не делаем

- Пуш «у вас идёт тест» (лишний шум; плашки достаточно).
- Автовозврат в монитор при запуске приложения (учитель мог выйти специально).
- Изменения в движке теста и в логике завершения.
- Возможность вести один тест с двух устройств одновременно сверх того, что уже есть.

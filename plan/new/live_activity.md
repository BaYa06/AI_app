# Live Activity «Серия под угрозой»

Вечером, если серия ещё не сохранена, на экране блокировки и в Dynamic Island появляется
карточка с обратным отсчётом до полуночи и сколько карточек осталось повторить. Нажатие сразу
открывает урок. Как только день засчитан, карточка показывает «Серия сохранена» и уходит.

Это не реклама приложения, а живое событие со сроком (как таймер или доставка). Ровно так Apple
и задумывала Live Activities.

Макет: plan/ideas/Flashly new version.html, экраны «Экран блокировки» и «Dynamic Island».
Ниже он переведён на брендбук; что изменилось — в разделе «Внешний вид».

Шаг = коммит «Live N». Отмечать ✅ по мере выполнения. Делать **после** plan/new/app_update_prompt.md.

Главная метрика — **доля вечеров «под угрозой», в которые серию спасли**: с Live Activity
против одного пуша `streak_risk` (эксперимент, Live 8).

---

## Правила (источник правды)

| Правило | Значение |
|---|---|
| Кому | iOS 16.2+; серия ≥ 1; сегодня день ещё не засчитан (`dayCountsForStreak`); **нет заморозок**: с заморозкой серия не сгорит, и пугать нечестно (как `streak_risk`); Live Activities разрешены в системе (`areActivitiesEnabled`) и не выключены в приложении |
| Когда появляется | с 20:00 по поясу пользователя (младше 18 — с 19:30, тихие часы у них с 21:00). Позже 23:00 не запускаем: на отсчёт меньше часа смотреть тревожно, а не полезно |
| Как появляется | **а)** Приложение открыто в это окно → запускаем сами. **б)** iOS 17.2+ → сервер запускает пушем (push-to-start) в 20:00. Это главный путь: кто в опасности, тот приложение как раз не открывает |
| Когда уходит | день засчитан → «Серия сохранена · 6 дней», через 15 минут исчезает; полночь → сервер завершает без следа; в любом случае приложение при следующем открытии закрывает всё устаревшее |
| Сколько | не больше одной карточки и одного запуска в день |
| Смахнул карточку | сегодня больше не запускаем. Смахнул 2 раза за 7 дней → пауза 14 дней |
| Вместе с пушем | Live Activity **заменяет** вечерний `streak_risk`, а не дополняет его. Запуск пушем приходит со звуком и текстом `streak_risk`, второй пуш не шлём |
| Нажатие | вся карточка и кнопка «Повторить сейчас» → `flashly://lesson?from=live` (сразу урок дня, как виджет). App Intent не нужен |
| Отсчёт | `Text(timerInterval: now...midnight)` — считает сама система, без обновлений и батареи |
| Прогресс | «3 из 10»: цель = `min(10, повторено + ждёт)`, как `dayCountsForStreak`. Обновляет приложение во время урока и сервер, если занимался на другом устройстве |

**Почему не весь день.** Утром и днём серия не «под угрозой». Карточка с отсчётом в 12 часов
приучит её не замечать. Вечер — момент, когда напоминание действительно меняет решение.

**Почему мы, а не только пуш.** Пуш видно секунду, потом он теряется среди других. Карточка с
идущим временем остаётся на экране блокировки весь вечер, и каждый взгляд на телефон
напоминает о серии.

## Внешний вид (брендбук)

Карточка всегда тёмная (как в макете). Экран блокировки почти всегда поверх обоев, и своя
тёмная плашка читается одинаково на любых.

### Экран блокировки
| Элемент | Значение |
|---|---|
| Фон | `activityBackgroundTint` `#1A1B30` (`surface` тёмной темы), рамка не нужна |
| Шапка | SF Symbol `flame.fill` 16 цвета `streak` `#F97316` + «Серия: 5 дней» (`label`, 600, `streak`); справа «Flashly» (`caption`, `#9CA3AF`) |
| Отсчёт | системный шрифт 44, 700, `monospacedDigit`, `#F9FAFB` |
| Подпись | «Повтори ещё 7 карточек — и серия сохранится» (`bodySmall`, `#9CA3AF`), до 2 строк |
| Стопка карточек справа | две карточки 56×66, скругление 12: нижняя `#4F46E5`, верхняя `primaryFill` `#6366F1` с рамкой `#818CF8`, на верхней число оставшихся (`h3`, белый) |
| Прогресс | полоса высотой 8, скругление `full`, фон `#2A2C47`, заливка `streak`; справа «3 из 10» (`caption`, `#9CA3AF`) |
| Сохранено | огонь `success` → «Серия сохранена», крупно «6 дней подряд», без отсчёта и полосы |

### Dynamic Island
- **Компактный:** слева `flame.fill` (`streak`), справа отсчёт `h:mm:ss` (`streak`,
  `monospacedDigit`).
- **Минимальный:** огонь внутри кольца прогресса (кольцо `streak`, фон `#2A2C47`). Видно и
  «сколько осталось», и что это серия.
- **Раскрытый:** «Серия под угрозой» (`label`, `streak`), отсчёт 38, подпись «Ещё 7 карточек —
  и серия сохранена»; справа огонь в круге `streak` + `1A`; снизу кнопка «Повторить сейчас»
  (`primaryFill`, высота 48, скругление 12).

**Что поменяли относительно макета и почему:**
- Огонь `#F59E0B` → `streak` `#F97316`. По брендбуку серия всегда в `streak`, а `#F59E0B` — это
  `warning` и звёзды.
- Синий `#2F6FBF`/`#7FB0F0` → `primaryFill`/`primary` тёмной темы. Градиент обоев в макете — это
  фон телефона, не наш.
- Manrope → системный шрифт (SF Pro), цифры моноширинные, чтобы отсчёт не дрожал.
- Иконки — SF Symbols, как в виджете `FlashlyWidget.swift` (`bolt.fill`). lucide в SwiftUI нет.
- Кнопка-таблетка → скругление 12 (кнопки по брендбуку).
- «0 из 10» с полоской 6 % → честный 0 %: полоса пустая, если ничего не повторено.
- **Две плитки под карточкой** («Урок дня · 20 слов ждут» и «1 день») — это виджеты экрана
  блокировки, а не часть Live Activity. Не делаем: на блокировке уже есть виджет «Вспомни
  слово» (plan/done/widgets.md), третий источник того же числа — шум.

## Как устроено

```
JS (liveActivityPlanner.ts: решает)           Swift (только рисует и передаёт)
  startIfNeeded / update / end  ──bridge──▶   LiveActivityBridge → ActivityKit
  ◀── pushToStartToken, pushToken, dismissed ──
Сервер (api/push.js)
  cron 20:00 → push-to-start (iOS 17.2+), иначе обычный streak_risk
  день засчитан (updateUserStatsStreak) → end-пуш на токен активности
  cron 00:05 → end-пуш тем, у кого карточка ещё висит
```

- `StreakActivityAttributes` — один файл в обоих таргетах (приложение и `FlashlyWidget`).
  `ContentState { streak, reviewed, target, deadline, saved }`.
- Таргет виджета остаётся iOS 16.0. `ActivityConfiguration` — под `if #available(iOS 16.2, *)`
  в `FlashlyWidgetBundle`. Push-to-start — под `#available(iOS 17.2, *)`.
- Как и в виджете, логика живёт только в JS и на сервере. Swift ничего не решает.

## Слабые места
1. **Push-to-start есть только с iOS 17.2.** На 16.2–17.1 карточка появится, только если человек
   сам откроет приложение вечером. Таким нужен обычный пуш.
2. **Ревью Apple.** Live Activity не для рекламы. В заметках для ревью: «отсчёт до конца дня,
   чтобы сохранить серию занятий; появляется только вечером, если день не засчитан; выключается
   в настройках». Со скриншотом.
3. **Пояс.** Полночь считаем по `user_stats.timezone`, как серию на сервере. Если человек
   улетел, а пояс не обновился, отсчёт не совпадёт с его полуночью.
4. **Не тревожить.** Карточка с тикающим временем давит. Отсюда 23:00 как предел, пауза после
   смахиваний и замена пуша, а не добавка к нему.

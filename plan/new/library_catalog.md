# Библиотека-каталог: предмет → подборка → набор

Библиотека больше не маркетплейс, а курс, который ведёт команда. Ученик идёт по иерархии
«предмет → (язык или раздел) → (уровень) → подборка → набор» и на каждом экране видит не больше 6–8 вариантов.
Наборы в подборке идут от простого к сложному. Лайков, оценок, скачиваний и «Популярных» нет.

- Идеология: текст «Идеология библиотеки Flashly» от 04.11.2026 (в чате), исходный макет `plan/ideas/Flashly Библиотека.html`.
- Прототип в цветах брендбука: https://claude.ai/artifact/KxYbGXmFM4LXqm8na41cKs. Экраны, роль учителя, новичок,
  модель данных и правила для пустых уровней.

Шаг = коммит «Catalog N». Отмечать ✅ по мере выполнения. **Код не трогаем, пока не будет команды начинать.**

---

## Решения (04.11.2026)

1. **Нижнюю панель не меняем.** Главная · Библиотека · Тест · Профиль. Новые экраны открываются внутри вкладки «Библиотека».
2. **Прогресс обучения не считаем.** Везде пишем «добавлено N из M», число берём из `library_imports`.
   Слово «пройдено» и проценты не используем.
3. **Обновления каталога до учеников не доходят.** Копия у ученика остаётся такой, какой её добавили.
   Повторный импорт из Excel меняет только библиотеку.
4. **Иерархия хранится в таблицах.** Предмет и подборка — отдельные таблицы, у набора добавляются подборка и порядок
   (раздел «Модель данных»).
5. **Премиума пока нет.** Без замков, бейджей и баннера. Поле `is_premium` в схему не добавляем.
6. **Учебники — отдельный блок.** Полка на первом экране, экран «Все учебники», экран книги в виде подборки,
   плюс «Учебники этого уровня» на экране «Языки». Учебники остаются в своих таблицах (`books` → юниты → наборы).
7. **У учителя есть кнопки «в курс».** На наборе «В мой курс», на подборке «Подборку в мой курс»,
   на книге «Подключить к курсу» (это уже есть, `course_books`).
8. **Пользовательской публикации нет.** Убираем лайки, оценки, жалобы, счётчик скачиваний, полки «Популярные»
   и «Лучшие по рейтингу», статус «Импортировано».
9. **Шкала у каждого предмета своя, пустое скрываем.** См. «Правила показа».
10. **Один Excel-файл для всех предметов.** Пять уровней, из них L2 и L3 можно не заполнять (см. «Формат Excel»).
    Шесть уровней с «под-наборами» не делаем: если в подборке больше 8 наборов, её делят на две.

## Иерархия

| | Уровень | Обязательно | Пример | Экран |
|---|---|---|---|---|
| L1 | Предмет | ✔ | Языки | плитка на «Библиотеке» |
| L2 | Раздел / язык (`track`) | если есть у предмета | Английский | ряд чипов на экране предмета |
| L3 | Уровень (`level`) | если есть у предмета | A2 | ряд-переключатель под чипами |
| L4 | Подборка | ✔ | Путешествия | список на экране предмета |
| L5 | Набор с карточками | ✔ | Аэропорт | список на экране подборки |

Шкала предметов на старте:

| Предмет | L2 (`track_label`) | L3 (`level_scale`) |
|---|---|---|
| Языки | «Язык»: en, de, tr… | `cefr`: A1–C2 |
| История | «Раздел»: Кыргызстан, Всемирная | `stages`: Основы / Углублённо |
| География | нет | нет |
| ОРТ и НЦТ | «Раздел»: Математика, Аналогии, Чтение, Грамматика | нет |
| Наука | нет | нет (плитка скрыта, пока нет подборок) |

Новый предмет — это одна строка в `library_subjects`. Интерфейс менять не нужно.

## Правила показа

1. Предмет виден, если в нём есть хотя бы одна опубликованная подборка.
2. Язык или раздел виден, если в нём есть подборки.
3. Уровень виден, если на нём есть подборки для выбранного языка или раздела.
4. Если остался один вариант, ряд выбора не рисуем, а под заголовком ставим бейдж («Турецкий · уровень A1»).
5. Подборка из меньше чем 3 наборов остаётся черновиком (проверка в скрипте импорта).
6. Экрана «Здесь пока пусто» в навигации нет: пустое не попадает в выбор.
7. Последний выбранный уровень запоминаем локально, отдельно для каждого языка или раздела.
8. Если предметов больше 8, показываем 6 плиток и ссылку «Все предметы».

## Экраны

1. **Библиотека.** Заголовок, поиск, карточка «Продолжить подборку», плитки предметов, полка «Учебники».
   Алмазов и серии в шапке нет (в исходном макете они есть, не переносим).
   - «Продолжить»: подборка, в которую ученик последним добавлял набор (`library_imports.imported_at`),
     в ней первый не добавленный набор по порядку. Если в ней всё добавлено, берём следующую по времени.
     Если не осталось ни одной, блока нет.
   - Новичок без добавлений видит «С чего начать»: первая подборка A1 на языке, выбранном при регистрации.
2. **Поиск.** Три группы: подборки, наборы, учебники, в каждой до 4–6 строк. У каждой строки путь
   («Английский · A2 · Путешествия»). Ищем по названиям подборок, наборов, книг и юнитов, без текста карточек.
3. **Предмет.** Чипы L2, переключатель L3, подсказка «наборы идут от простого к сложному», список подборок
   с «N наборов · добавлено k». Подборка, которую ученик сейчас добавляет, выделена рамкой.
   У языков внизу «Учебники этого уровня».
4. **Подборка.** «Добавлено k из N», сегментная полоска, наборы по порядку. Галочка у добавленных, рамка у следующего,
   «Добавить» в строке. Главная кнопка: «Добавить следующий: …». Замков нет, добавить можно любой набор.
   Учитель видит «Подборку в мой курс».
5. **Набор.** Число карточек, уровень, «Набор 3 из 8», превью первых 5 карточек, «Добавить в мои наборы».
   После добавления кнопки «Добавлен» и «Открыть и учить». Учитель видит «В мой курс». Внизу ссылка на следующий набор.
   Автора, лайка, оценки и «Пожаловаться» нет.
6. **Все учебники.** Один ряд чипов по языку, список книг.
7. **Учебник.** Обложка, издание, уровни, юниты по порядку в виде подборки. Ученик добавляет юниты,
   учитель видит «Подключить к курсу».

Цвета, шрифт, скругления — только токены брендбука (`plan/done/brandbook.md`). Цвета макета заменяем так:
синий `#2F6FBF` → `primary` / `primaryFill`, тёмный текст → `textPrimary`, серый → `textSecondary`,
подложки → `surfaceMuted` / `primary` 10%, «Готово» / «Добавлен» → `successText`, Manrope → системный шрифт,
скругления 18–24 → `borderRadius.l` (16).

## Модель данных

**`library_subjects`** (новая):

| поле | тип | зачем |
|---|---|---|
| `id` | uuid | |
| `slug` | text unique | `languages`, `history`, `geography`, `ort` — ключ в Excel |
| `title`, `subtitle`, `icon` | text | «Языки», «Английский, немецкий, турецкий», имя иконки lucide |
| `track_label` | text null | «Язык» / «Раздел». NULL — ряда L2 нет |
| `level_scale` | text null, `CHECK IN ('cefr','stages')` | шкала L3. NULL — уровней нет |
| `set_kind` | text, `CHECK IN ('language','subject')` | тип наборов предмета (план Kind): языки → `language`, остальное → `subject` |
| `position` | int | порядок плиток |
| `is_published` | bool | скрыть предмет целиком |

**`library_collections`** (новая):

| поле | тип | зачем |
|---|---|---|
| `id` | uuid | |
| `subject_id` | uuid → `library_subjects` | |
| `track` | text null | для языков код языка (`en`), он совпадает с `language_from` наборов. Для разделов ключ (`math`, `kg`) |
| `level` | text null | `A1`…`C2`, `basic` / `advanced` или NULL |
| `title`, `description`, `icon` | text | |
| `position` | int | порядок в списке на экране предмета |
| `status` | text | `draft` / `published` / `archived`, как у наборов |
| unique | | `(subject_id, track, level, title)` — по нему подборка находится при повторном импорте |

Уровень хранится у подборки, а не у набора: «Путешествия A2» и «Путешествия B1» — разные подборки,
и одна подборка не может оказаться на двух уровнях.

**Названия разделов** (`Математика` для `math`) хранятся в `library_tracks (subject_id, key, title, position)`.
Для языков названия берём из существующего списка языков приложения, строки в таблице не нужны.

**`library_sets`** (добавляем):
- `collection_id uuid null` → `library_collections`. NULL — набор не показывается в каталоге, только в поиске
  и в старых версиях приложения (переходный период).
- `position int null`. Номер в подборке, уникален внутри подборки (`UNIQUE (collection_id, position)`).

**`library_imports`** (меняем): добавить `course_id uuid null`, уникальность
`(user_id, library_set_id, course_id) NULLS NOT DISTINCT`. Сейчас учитель, который добавил набор себе,
не может положить его в курс («Set already imported»), а один набор нельзя положить в два курса.
«Добавлено» для ученика считается по строкам с `course_id IS NULL`.

**Убираем** (не сразу, см. «Слабые места», п. 1): `library_likes`, `library_ratings`, `library_reports`,
поля `likes_count`, `rating_sum`, `rating_count`, `is_featured`. `imports_count` оставляем для аналитики,
но в интерфейсе не показываем.

**Учебники** — схема книг не меняется. Полка читает `books` с `is_published`.

**`book_unit_imports`** (новая, решено 05.11.2026): какие юниты учебника ученик добавил себе сам, без курса.

| поле | тип | зачем |
|---|---|---|
| `id` | uuid | |
| `user_id` | uuid | кто добавил |
| `unit_id` | uuid → `book_units` | **юнит, а не набор внутри него**: если книгу перезальют и официальный набор юнита сменится, отметка останется верной |
| `card_set_id` | uuid null | копия в «Моих наборах». По ней отметка снимается при удалении копии |
| `imported_at` | timestamptz | |
| unique | | `(user_id, unit_id)`: двойное нажатие не создаёт вторую копию |

`library_imports` для юнитов не трогаем: импорт из библиотеки работает как раньше.

## Формат Excel

Один файл на все предметы. Скрипт `scripts/import-library.ts` (план `plan/done/library_import.md`) расширяется.

**Лист «Предметы»** (необязательный, нужен при первом заведении предмета или его изменении):
`slug | title | subtitle | icon | track_label | level_scale | set_kind | position`.

**Лист «Разделы»** (необязательный): `subject | key | title | position`.

**Лист «Наборы»**:

| subject | track | level | collection | position | title | language_from | language_to | description |
|---|---|---|---|---|---|---|---|---|
| languages | en | A2 | Путешествия | 1 | Аэропорт | en | ru | |
| languages | en | A2 | Путешествия | 2 | Отель | en | ru | |
| history | kg | basic | Древние государства | 1 | Саки и усуни | ru | ru | |
| geography | | | Столицы Азии | 1 | Центральная Азия | ru | ru | |
| ort | math | | Дроби и проценты | 1 | Дроби | ru | ru | |

Колонку `category` больше не заполняем: она выводится из предмета для совместимости со старыми версиями.
`kind` набора берётся из `set_kind` предмета.

**Лист «Карточки»** как сейчас: `set | term | translation | example`.

Проверки до записи в базу:
- предмет существует (в базе или на листе «Предметы»);
- `track` пустой, если у предмета нет `track_label`, и заполнен, если есть; раздел известен;
- `level` подходит к шкале предмета: A1–C2 для `cefr`, `basic` / `advanced` для `stages`, пусто, если шкалы нет;
- у языков `track` совпадает с `language_from`;
- `position` внутри подборки начинается с 1 и идёт без пропусков и повторов;
- в подборке не меньше 3 наборов, в наборе не меньше 5 карточек, нет дублей `term`.

Повторный импорт: подборку ищем по `(subject, track, level, collection)`, набор — как сейчас
(`title + language_from + language_to` у автора «Flashly»). Порядок и подборку обновляем,
карточки заменяем целиком. Копии у учеников не трогаем (решение 3).

## Слабые места и как закрываем

1. **Старые версии приложения** вызывают `list` с сортировкой по популярности, `like`, `rate` и `report`.
   `list` и `id=` продолжают работать как сейчас. `like` / `rate` / `report` отвечают 200 без действия.
   Таблицы удаляем только после того, как минимальная версия приложения (Release) станет новой.
2. **Порядок выкладки:** сервер (Catalog 1–4) в main → Vercel, проверка текущей версии из App Store,
   потом сборка. Поднять `SCHEMA_VERSION` (сейчас `schema_039` → `schema_040`), иначе миграция не выполнится
   (урок Kind 1, 03.11.2026). Перед выкладкой проверить колонки в Neon.
3. **Уже опубликованные наборы без подборки** пропадут из каталога. До выкладки клиента разложить их по подборкам
   повторным импортом (Catalog 11). До этого они видны в поиске.
4. **Удалённая копия.** Если ученик удалил свою копию, набор не должен оставаться «добавленным».
   `library_imports.card_set_id` ссылается на копию с `ON DELETE CASCADE`: удалил набор (или учитель удалил курс
   вместе с наборами) — строка исчезает сама, код удаления не меняется. Заполнять при импорте (Catalog 4).
   У старых строк `card_set_id` NULL: их отметки остаются как были.
5. **Хвост «(из библиотеки)»** в названии копии убираем: источник и так записан в `library_imports`.
6. **Юниты учебника у ученика без курса** (решено 05.11.2026: вариант 1, отдельная таблица `book_unit_imports`).
   `library_imports` ссылается только на `library_sets`, а общую таблицу не делаем: её миграция может сломать
   работающий импорт из библиотеки и отметки в старых версиях. Три правила:
   - **Удалил копию — отметка снимается.** `book_unit_imports.card_set_id` с `ON DELETE CASCADE`,
     так же как у `library_imports`.
   - **Отметка ставится на юнит** (`unit_id`), а не на официальный набор: перезаливка книги её не сбивает.
   - **Книга уже в курсе ученика.** Если книга подключена к курсу, где он ученик (`course_books`), вместо «Добавить»
     показываем «Есть в курсе». Добавить себе вторую копию нельзя, иначе будет два «Юнита 1».

   Ограничение: «Продолжить» на первом экране учитывает только подборки библиотеки, юниты туда не попадают.
7. **Контент — узкое место.** Запускаться только с предметами, где есть полные подборки. Нужен ответственный
   за порядок наборов и приём новых подборок.
8. **Кэш на телефоне.** Каталог меняется редко: кэшировать дерево предметов и подборок, «добавлено» обновлять
   после каждого импорта без перезагрузки всего дерева.

## Проверка

1. Импорт с `--dry-run` ловит каждую ошибку из списка проверок; повторный импорт не плодит подборки и наборы.
2. Предмет без подборок не виден. Язык с одним уровнем показывает бейдж вместо переключателя.
   «Всемирная» история без «Углублённо» не показывает переключатель.
3. «Добавлено k из N» совпадает с `library_imports`. После удаления копии набор снова «не добавлен».
4. Учитель кладёт один набор себе и в два разных курса без ошибки. «Подборку в мой курс» не дублирует наборы.
5. Новичок видит «С чего начать», после первого добавления — «Продолжить».
6. Юнит учебника: двойное нажатие даёт одну копию; после удаления копии юнит снова «не добавлен»;
   после перезаливки книги отметка на месте; у ученика курса с этой книгой — «Есть в курсе».
7. Старая версия из App Store: библиотека открывается, импорт работает, лайк не падает.
8. Тёмная тема и экран 375 pt: ничего не обрезается.

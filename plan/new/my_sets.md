# «Мои наборы» вместо «Все наборы»

Сейчас «Все наборы» — не папка, а показ всех наборов сразу: набор, созданный в курсе, виден и
в курсе, и во «Всех». Удалить курс с наборами нельзя — сначала нужно их перенести.

Новая модель: каждый набор живёт ровно в одном месте.
- **«Мои наборы»** — курс по умолчанию. В нём только наборы без курса (`courseId = null`).
- **Свой курс** — только его наборы. В «Моих наборах» они не появляются.
- **Удаление курса** удаляет и все его наборы, после галочки «Я понимаю».

Шаг = коммит «MySets N». Отмечать ✅ по мере выполнения.

---

## Решения (31.10.2026)

1. **«Мои наборы» — не новый курс в базе, а то же `activeCourseId = null`.** Меняется только
   фильтр: `null` показывает наборы без курса, а не все. Миграция данных не нужна, старые наборы
   без курса сами оказываются в «Моих наборах».
2. **Повторения на главной — из всех курсов.** Иначе карточки из «Английского» никто не
   повторит, пока открыты «Мои наборы». «Урок дня», счётчик «N карточек к повторению» и
   напоминания считают все наборы пользователя, независимо от открытого курса. Список наборов
   на главной — только открытого курса.
3. **Наборы ученика (курс преподавателя) и юниты книг** видны только в своём курсе
   (`isSetInCourse`), во «Моих наборах» их нет.
4. **Окно удаления курса.** Кнопка «Удалить» доступна только после галочки. Текст с числами:
   > Вместе с курсом удалятся 5 наборов и 240 карточек, а также весь прогресс по ним.
   > Вернуть их будет нельзя.
   >
   > ☐ Я понимаю, что наборы и прогресс удалятся навсегда

   Под ним подсказка: «Хочешь сохранить набор? Сначала перенеси его в „Мои наборы“».
   Пустой курс удаляется без галочки, как сейчас.
5. **Курс с учениками** — та же галочка (вводить название не нужно), но в тексте добавляется
   строка: «У 12 учеников пропадут наборы этого курса».
6. **Перенос набора.** В меню набора — «Переместить в курс…» (список курсов + «Мои наборы»).
   Только для своих наборов; read-only и юниты книг не переносятся.
7. **Сервер и старые версии** (plan/new/release_safety.md). Сейчас `card_sets.course_id` —
   `ON DELETE SET NULL` (002_add_courses.sql), то есть сервер наборы не удаляет. Новый запрос
   `delete-course` с флагом `withSets: true` удаляет наборы курса (и их карточки) в одной
   транзакции. Без флага — старое поведение: старые версии и так не дают удалить курс с
   наборами, поэтому для них ничего не меняется. Сервер выкатывается раньше сборки.
8. **«Что нового».** Новость: «Наборы теперь живут в своих курсах» — объясняет, почему наборы
   курсов пропали из общего списка (plan/new/whats_new.md).

## Слабые места

### 1. Человек не находит набор
Набор из курса больше не виден в «Моих наборах». Новость в «Что нового» + в пустом состоянии
«Моих наборов» при наличии курсов: «Наборы курсов — внутри курсов. Открыть список курсов».

### 2. Синхронизация удаления
Удалили курс офлайн → локально наборы удалены сразу, на сервер уходит `delete-course` с
`withSets`. Если запрос не прошёл — повторить при следующей синхронизации, иначе при загрузке
наборы вернутся (уже без курса, в «Мои наборы»). Проверить очередь синхронизации.

### 3. Активный курс указывает на удалённый
После удаления — переключение на «Мои наборы» (уже есть в `coursesStore.deleteCourse`).

## Шаги

### MySets 1 — фильтр «Мои наборы» ✅
- `setsStore.getSetsByCourse(null)` → только наборы без курса и не принадлежащие курсу
  (`!s.courseId && !s.officialCourseIds?.length`).
- `HomeScreen.new.tsx:617` — тот же фильтр для `activeCourseId === null`.
- Переименование «Все наборы» → «Мои наборы»: `CoursesDrawer.tsx:585`, подзаголовок
  `HomeScreen.new.tsx:2230`, логи «All».
- Создание набора в «Моих наборах» — `courseId: null`, в курсе — id курса (проверить
  `SetEditorScreen`, ИИ-импорт, «Поделиться набором», библиотеку).
- Сделано: `isSetInMySets` в `setsStore.ts` (+ тест). Свой набор, чей курс пропал, тоже в
  «Моих наборах», чтобы не потеряться. Импорт файлов (`PreviewImportScreen`) раньше всегда
  создавал набор без курса — теперь кладёт в открытый свой курс. Редактор, библиотека и
  «Поделиться» уже так делали.
- До MySets 2 «Урок дня» в «Моих наборах» берёт только их наборы.

### MySets 2 — повторения из всех курсов ✅
- «Урок дня»: повторение — из всех наборов пользователя, новые слова — из открытого курса
  (`buildLessonPlan({ sets, newFrom })`). «Сменить набор» и «новых осталось на N дней» — тоже
  по открытому курсу.
- Добор теста до 4 вопросов и виджет — по всем словам (`lessonCards`).
- Остаются по открытому курсу: счётчики «N ждут» у наборов, «Учить всё» и число карточек в
  его окне — это действие с курсом.
- Пустой курс: карточка урока всё равно видна, если в других курсах есть слова.
- Пуши сервер и так считает по всем наборам (`api/push/_arbiter.js`) — без изменений.
- Тест: новые только из `newFrom`, повторение из всех.

### MySets 3 — сервер: удаление курса с наборами ✅
- `api/teacher.js` `deleteCourse`: при `withSets: true` в транзакции удалить карточки и наборы
  курса (`card_sets.course_id = courseId AND user_id = userId`), затем курс.
- Вернуть `{ ok, deletedSets }`. Без флага — как сейчас.
- `NeonService.deleteCourse(courseId, { withSets })`.
- Сделано: проверка владельца, затем одна транзакция (карточки → наборы → курс), как
  `deleteSet` в `api/data.js`. Клиент флаг пока не шлёт — включится в MySets 4. Сервер нужно
  выкатить (Vercel) раньше сборки с MySets 4.

### MySets 4 — окно удаления с галочкой ⬜
- `HomeScreen.new.tsx` окно «Удаление курса»: числа наборов и карточек, строка про учеников
  (если есть), галочка, подсказка про перенос. Убрать блокировку «сначала перемести наборы».
- `coursesStore.deleteCourse(id)` → удалить наборы курса локально (вместо `moveSetsFromCourse`)

- `moveSetsFromCourse` оставить только для `removeLocalCourse` (выход ученика из курса —
  read-only наборы там и так удаляются).

### MySets 5 — «Переместить в курс…» ⬜

### MySets 6 — пустое состояние и «Что нового» ⬜

# Что нового

После обновления приложения пользователь при заходе на главную видит шторку «Что нового»:
одна страница — одна новость, листается свайпом. Новости короткие, у каждой может быть кнопка
«Попробовать», которая открывает нужный экран. История всех новостей — в Профиле.

Прототип: https://claude.ai/artifact/BTzTs1eqaM9x69LLBzw85x

Шаг = коммит «News N». Отмечать ✅ по мере выполнения.

---

## Решения (31.10.2026)

1. **Храним просмотренные новости, а не последнюю версию.** В MMKV — список `id` просмотренных
   новостей (`whatsNew.seen`). Так версия без новостей (как 1.6.6 — только исправление сборки)
   окно не открывает, а кто пропустил несколько версий, видит всё непросмотренное за них.
2. **Новичку не показываем.** Кто только установил приложение, не знает, «как было раньше».
   Все текущие новости тихо отмечаются просмотренными (как определить новичка — слабое место 1).
3. **Только на главной и только при обычном запуске.** Не показываем, если приложение открыли
   по ссылке `/s/<code>`, по пушу, по приглашению в курс, во время теста. Ждём, пока главная
   загрузится (скелетон сменился данными) + ~1 с, чтобы человек увидел свой экран.
4. **Не больше одного окна за запуск.** Порядок: приглашение в курс → «Что нового». Просьба
   оценить приложение в тот же день, что и «Что нового», не показывается.
5. **Максимум 4 страницы.** Сортировка по `priority`. Если новостей больше четырёх — первые три
   отдельными страницами, остальные списком на последней странице «И ещё».
6. **Фильтры у каждой новости:** роль (`student` / `teacher`), платформа (`ios` / `android` / `web`),
   `minVersion`, `minOs` (например, стекло только на iOS 26), `expiresAt`.
7. **Тексты с сервера, запасная копия в сборке.** Опечатку можно исправить без релиза.
   Картинки — не файлы, а готовые иллюстрации в коде (`art: 'swipe' | 'share' | …`): работают
   без интернета и сразу, без загрузки. Новая иллюстрация = новая сборка, поэтому новость с
   незнакомым `art` показывается без картинки (а не ломается).
8. **Просмотрено = показано.** Закрыл окно на любой странице — все показанные в нём новости
   считаются просмотренными. Повторно окно с ними не открывается. Перечитать можно в Профиле.
9. **На iOS окно целиком на Swift.** `UISheetPresentationController` + содержимое на SwiftUI —
   тот же подход, что `StudyModeSheet.swift` (Glass 0.1). Листание страниц, свайп вниз и анимации
   делает система, поэтому всё плавно, без рывков RN-шторки. JS только решает, *когда* и *что*
   показать, и передаёт готовые страницы. На Android и вебе — то же окно на RN (`Modal`).
10. **Внешний вид.** По брендбуку:
   надпись `overline` «ЧТО НОВОГО · 1.6.9», иллюстрация, тег, заголовок `h2`, текст `body`,
   ссылка «Попробовать →», точки-страницы, главная кнопка «Дальше» / «Понятно». Крестик виден
   всегда. Закрывается свайпом вниз и кнопкой «Назад» на Android.

### Правила для текста
- Заголовок ≤ 40 символов (две строки), описание ≤ 140 символов — одна мысль, одна польза.
- На «ты», про пользу, а не про техническую работу: «Опыт больше не завышается», а не «исправлен расчёт XP».
- Одна иллюстрация, которая показывает действие (свайп, ссылку), а не логотип.
- Новость про то, что видно только на одной платформе, — с тегом «Только iPhone».

### Формат новости
```json
{
  "id": "cards-swipe",
  "minVersion": "1.6.9",
  "roles": ["student"],
  "platforms": ["ios", "android"],
  "minOs": null,
  "priority": 10,
  "tag": "Карточки",
  "title": "Свайпай карточку",
  "text": "Влево — «Не знаю», вправо — «Уверенно». Или жми одну из трёх кнопок.",
  "art": "swipe",
  "action": { "label": "Попробовать", "route": "Study" },
  "publishedAt": "2026-10-28",
  "expiresAt": "2027-01-31"
}
```
`version` в истории Профиля берётся из `minVersion`. `id` никогда не меняем — иначе новость покажется снова.

## Слабые места и как закрываем

### 1. Первая версия с этой функцией: все выглядят новичками
В версии, где появится «Что нового», ключа `whatsNew.seen` нет **ни у кого** — и у новичка,
и у того, кто пользуется приложением полгода. Если считать «нет ключа = новичок», окно не увидит никто.
- **Решение:** при первом запуске без ключа смотрим, вошёл ли человек уже в аккаунт
  (`isAuthenticated && !needsOnboarding` в App.tsx). Вошёл → это старый пользователь, ключ = `[]`,
  новости покажем. Не вошёл → ставим флаг `whatsNew.markOnSignIn`; после входа/онбординга
  отмечаем все текущие новости просмотренными.
- Вход на новом устройстве в старый аккаунт идёт через экран входа → тоже считается новичком.
  Это нормально: на новом телефоне «что нового» по сравнению с прошлым не понятно.

### 2. Сервер знает новость, а у человека старая сборка
По plan/new/release_safety.md сервер обновляется раньше сборки. Новость про функцию из 1.7.0
придёт и в 1.6.9. Закрывает `minVersion`: сравниваем с версией из `package.json`
(как в ProfileScreen.tsx / feedback.ts). Когда человек обновится, новость покажется.

### 3. Поэтапный выпуск (phased release)
Новость публикуем на сервере заранее — это безопасно благодаря `minVersion`: её увидят только
те, кому уже пришла новая версия.

### 4. Лимит функций Vercel
В `api/` уже 11 функций из 12 (Hobby). Новую функцию не заводим:
- чтение — `GET /api/data?action=news` (публично, CDN-кэш `s-maxage=300`);
- правка — только локально: `admin-server.mjs` (`/admin-api?action=news-list | news-save | news-publish |
  news-delete`), раздел «Что нового» в public/admin.html; запросы — `api/_whatsNew.js`.

### 5. Нет интернета или сервер не ответил
Показываем запасную копию из сборки (`src/constants/whatsNew.ts`). Ответ сервера кэшируем в
MMKV, чтобы в следующий раз окно открылось сразу. Если запрос идёт дольше 3 с — берём кэш/копию,
не ждём.

### 6. Конфликт окон
Сейчас на главной сами всплывают только `CourseInviteModal` (App.tsx) и шторки, открытые по
ссылке на набор. `PushPreprompt` и `RatingPromptModal` живут на StudyResultsScreen, а
`WidgetPromptCard` — карточка внутри главной, не окно. Поэтому большая общая очередь не нужна:
- маленький модуль `src/services/modalGate.ts`: `claim('whatsNew')` / `release()` / `isBusy()`;
- `CourseInviteModal` и открытие набора по ссылке занимают его первыми;
- `RatingPromptModal` не показывается, если «Что нового» показывали сегодня (`whatsNew.lastShownDay`).

### 7. Человек закрыл окно сразу
Если закрыли на первой странице — один раз тост на главной: «Что нового — всегда в Профиле».

### 8. Две реализации окна: Swift и RN
Окно и иллюстрации нужно сделать дважды — SwiftUI для iOS и RN для Android/веба — и они могут
разъехаться.
- Логика (отбор, сжатие до 4 страниц, просмотренные) — **только в JS** (`whatsNew.ts`). В Swift
  приходят уже готовые страницы, Swift ничего не решает.
- Цвета передаём из `useThemeColors()` в `present(options)`, как `StudyModePalette` — своих
  цветов в Swift нет.
- Иллюстрации на Android/вебе можно делать проще (статичные), анимация — только на iOS.
- Незнакомый `art` в Swift → страница без картинки (сервер может прислать новый `art` раньше сборки).

### 9. Swift-файл не попал в сборку
Новый `.swift` и `.m` нужно добавить в `FlashcardsApp.xcodeproj` (как `StudyModeSheet`), иначе
модуль молча будет `null`. В JS обёртке: модуля нет → показываем RN-окно, приложение не падает.
Проверяем в TestFlight, локальную сборку Xcode не гоняем. После перехода на новую архитектуру
(plan/new/rn_upgrade.md) модуль на `RCTEventEmitter` работает через совместимость — как остальные.

### 10. Веб-версия
На вебе обновление приходит без установки. Работает так же (версия из `package.json` веб-сборки),
`platforms` должен включать `web`, иначе новость там не показывается.

## Шаги

### News 1 — данные и отбор ✅
- `src/types/whatsNew.ts` — тип `WhatsNewItem` (формат выше).
- `src/constants/whatsNew.ts` — запасная копия: новости 1.6.5–1.6.9 (свайп и три оценки,
  «Почти» в конце урока, поделиться набором, новые книги, честный опыт, стекло iOS 26),
  и «Мои наборы» (`my-sets`, текст и формат — в plan/new/my_sets.md, MySets 6).
- `src/services/whatsNew.ts` — чистые функции:
  - `selectNews(all, { seen, appVersion, role, platform, osVersion, today })` → отфильтровано и отсортировано;
  - `toPages(items)` → ≤ 4 страниц, лишнее в странице «И ещё»;
  - `load/save` списка `whatsNew.seen` в MMKV (StorageService), `markSeen(ids)`;
  - `initForInstall({ isSignedIn })` — слабое место 1.
- `src/services/__tests__/whatsNew.test.ts`: фильтры, сортировка, сжатие до 4, сравнение версий
  (`1.6.10 > 1.6.9`), незнакомый `art`, новичок / старый пользователь.

### News 2 — шторка на Swift (iOS) ✅
- `ios/FlashcardsApp/WhatsNewSheet.swift` — модуль `WhatsNewSheetModule: RCTEventEmitter`,
  по образцу `StudyModeSheet.swift`:
  - `present(options)`: `{ version, pages: [{ id, tag, title, text, art, actionLabel }], colors, dark }`;
    `dismiss()`;
  - `UIHostingController` в `UISheetPresentationController`: `.large()`, `prefersGrabberVisible`,
    `delegate` — закрытие жестом; фон `surface`, `overrideUserInterfaceStyle` по `dark`;
  - SwiftUI: `TabView` со стилем `.page` (свайп между страницами), свои точки, крестик,
    кнопка «Дальше» / «Понятно», ссылка «Попробовать →»;
  - иллюстрации по `art` на SwiftUI (`swipe`, `share`, `books`, `glass`, `xp`, `more`),
    анимация выключается при `accessibilityReduceMotion`;
  - текст через Dynamic Type (крупный шрифт не обрезается — страница прокручивается);
  - VoiceOver: «Страница 2 из 4», заголовок, текст.
- События обратно — `WhatsNewSheetEvent`: `{ type: 'page', id, index }`, `{ type: 'try', id }`
  (сначала закрытие листа, потом событие — переход не дёргается), `{ type: 'close', index }`
  (крестик, «Понятно» или жест).
- `ios/FlashcardsApp/WhatsNewSheet.m` — `RCT_EXTERN_MODULE`, оба файла в `project.pbxproj`.
- `src/components/whatsNew/nativeWhatsNewSheet.ts` — хук `useNativeWhatsNewSheet({ visible, version,
  pages, onPage, onClose })` как `nativeStudyModeSheet.ts`; `onClose({ index, tryItem? })` — закрыли
  (с «Попробовать» — `tryItem`). `isNativeWhatsNewSheet` — модуль есть в сборке.
- `toSheetPages(pages)` в whatsNew.ts — страницы для окна (одни и те же для Swift и RN).
- Увидеть окно можно только после News 3 (показ на главной).

### News 2.1 — то же окно на RN (Android, веб) ✅
- `src/components/whatsNew/WhatsNewSheet.tsx` — единая точка: на iOS с модулем — Swift, иначе
  общий `Sheet` + горизонтальный `FlatList` с `pagingEnabled` (страницы от края до края листа),
  те же точки, «Дальше» / «Понятно», крестик, «Попробовать →» и события. «Назад» на Android
  закрывает (`onRequestClose`). Точки — `adjustable` для TalkBack/VoiceOver.
- `src/components/whatsNew/WhatsNewArt.tsx` — статичные иллюстрации из токенов.
- `useWhatsNewOnHome` возвращает пропсы окна, главная рисует `<WhatsNewSheet {...whatsNew} />`.

### News 3 — когда показывать ✅
- `src/services/modalGate.ts`: какое окно открыто (`courseInvite` > `shareLink` > `whatsNew`) и
  «прерванный запуск». App.tsx отмечает открытие приглашения и набора по ссылке; ссылка, пуш
  (`pushOpens`) и виджет (`from=widget|push` у главной) прерывают запуск. Метка снимается, когда
  человек уходит с главной, — при следующем заходе окно покажется.
- `src/components/whatsNew/useWhatsNewOnHome.ts`: главная на экране, роль известна, свои окна
  главной закрыты, запуск не прерван, окна важнее нет → через 1 с `selectNews` → шторка.
  Новости отмечаются просмотренными в момент показа (`markShown`). Пришло приглашение или набор
  по ссылке, пока окно открыто, — окно закрывается. «Попробовать» ведёт только на вкладки.
- App.tsx: `initWhatsNew` — новичок или старый пользователь по сессии при первом запуске.
- `RatingPromptModal` не показывается в день показа «Что нового» (`wasWhatsNewShownOn`).
- С News 2.1 — на всех платформах.
- Тост «Что нового — всегда в Профиле» перенесён в News 4: до него пункта в Профиле нет.

### News 4 — история в Профиле ✅
- «Профиль → Приложение → Что нового»: счётчик непросмотренных (`unseenCount`), обновляется при заходе.
- `WhatsNewScreen`: новости по версиям, новые сверху (`newsHistory`) — с просмотренными и с истёкшим
  `expiresAt` (срок — только для окна). «Новое» у непросмотренных; нажатие открывает то же окно
  с одной новостью и отмечает её просмотренной. «Попробовать» — `openNewsAction` (newsContext.ts).
- Тост «Что нового — всегда в Профиле» — один раз, если окно закрыли на первой странице, не нажав
  «Попробовать» (`shouldShowProfileHint`, `profileHintShown`).

### News 5 — сервер и админка ✅
- Таблица `whats_new` (миграция 037, `schema_037`): поля формата + `published`.
- `GET /api/data?action=news` — без входа, `s-maxage=300`: `{ items, hidden }`. hidden — снятые с
  публикации, скрывают и новость из сборки. Новая функция Vercel не нужна (11 из 12).
- Приложение: `refreshNews()` грузит, пока идёт пауза на главной (не дольше 3 с), кэш в MMKV
  (`whats_new_remote`), `mergeNews` — сервер поверх сборки (тот же id — текст с сервера).
  Без сети, при ошибке или со старым сервером (400) — кэш или сборка. Битые записи отбрасываются.
- Локальная админка: список, форма со счётчиками 40 / 140, «Опубликовать» / «Снять» / «Удалить»
  (удалить — вернуть текст из сборки). Проверка формы — `validateNews` (тесты в whatsNewServer.test.ts).
- Порядок выпуска: сначала деплой API (создаёт таблицу), потом сборка. Старая сборка запрос не делает.

### News 6 — аналитика ⬜
- В `Analytics` (src/services/analytics.ts): `whats_new_shown { count, version }`,
  `whats_new_page { id, index }`, `whats_new_try { id }`, `whats_new_closed { index, count }`.
- Цель: больше половины открывших доходят до последней страницы. Если закрывают на первой —
  первая новость неинтересна, меняем `priority`.

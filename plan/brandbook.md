# Брендбук Flashly

Единый стиль для всех экранов приложения (iOS, Android, веб). Это **обязательный стандарт** для любого нового экрана и любой правки существующего.

> **Статус:** целевой стандарт. Часть приложения ему пока не соответствует (см. «Переход» в конце). Новый код пишем сразу по брендбуку, старый приводим по плану.

**Применение к существующим экранам:** меняется **только внешний вид** — цвета, шрифты, размеры, отступы, скругления, иконки. **Состав экранов не меняется:** кнопки, блоки, разделы, тексты и порядок элементов остаются как есть. Исключения, которые уже согласованы: подписи во вкладках, обращение на «ты» во всех текстах, удаление выдуманных данных. Остальные правила о составе (например, «одна главная кнопка на экран») — для новых экранов.

**Главное правило:** никаких «своих» значений в экранах. Цвет, размер шрифта, отступ, скругление берутся **только из токенов** в `src/constants/` (`colors.ts`, `typography.ts`, `spacing.ts`). Если нужного значения нет — сначала добавляем токен сюда и в `constants`, потом используем.

## 1. Бренд

| | |
|---|---|
| Название | **Flashly** (всегда латиницей, с большой буквы, не переводится) |
| Знак | молния (lucide `Zap`) в цвете `primary` |
| Слоган | «Учись умнее. Запоминай надолго.» |
| Характер | дружелюбный, спокойный, поддерживающий. Хвалим за прогресс, не ругаем за ошибки |
| Аудитория | школьники и студенты (основная), учителя (B2B) |

## 2. Цвета

Все цвета — токены из `src/constants/colors.ts`, доступ через `useThemeColors()`. **Писать `'#…'` в экранах запрещено.**

### 2.1 Бренд

| Токен | Светлая | Тёмная | Где использовать |
|---|---|---|---|
| `primary` | `#6467F2` | `#818CF8` | главные кнопки (светлая тема), активные состояния, ссылки, иконки-акценты, прогресс |
| `primaryPressed` 🆕 | `#4F46E5` | `#6366F1` | нажатое состояние главной кнопки |
| `primaryFill` 🆕 | `#6467F2` | `#6366F1` | **заливка главных кнопок**. В тёмной теме `primary` (`#818CF8`) слишком светлый под белый текст (контраст 2,98) — кнопки заливаем `#6366F1` (4,47) |
| `onPrimary` 🆕 | `#FFFFFF` | `#FFFFFF` | текст и иконки на `primaryFill` |
| `secondary` | `#8B5CF6` | `#A78BFA` | только второстепенные акценты (бейджи, иллюстрации). Не для кнопок |

**Оттенки для фонов-подложек** (выделенная карточка, фон иконки, активный чип): цвет токена + прозрачность только из трёх ступеней:

| Ступень | Суффикс | Пример |
|---|---|---|
| 10 % | `1A` | `colors.primary + '1A'` — фон иконки, выделенная строка |
| 20 % | `33` | фон бейджа |
| 40 % | `66` | рамка акцента |

Любые другие суффиксы (`'08'`, `'15'`, `'22'`, `'30'`, `'60'` …) не используем.

> ⛔ `#6366F1` в светлой теме как «фиолетовый» — запрещён (это второй, чужой фиолетовый). Только `primary`.

### 2.2 Смысловые

Разделяем **заливку** (фон, иконка, полоса прогресса) и **текст** — светлые заливки нечитаемы как текст на белом.

| Смысл | Заливка (свет / тёмн.) | Текст на фоне (свет / тёмн.) | Когда |
|---|---|---|---|
| Успех | `success` `#10B981` / `#34D399` | `successText` 🆕 `#047857` / `#34D399` | правильный ответ, выучено, сохранено |
| Ошибка | `error` `#EF4444` / `#F87171` | `errorText` 🆕 `#DC2626` / `#F87171` | неверный ответ, ошибка, удаление |
| Предупреждение | `warning` `#F59E0B` / `#FBBF24` | `warningText` 🆕 `#B45309` / `#FBBF24` | серия под угрозой, лимит |
| Информация | `info` `#3B82F6` / `#60A5FA` | `info` | подсказки, новые карточки |

## 3. Типографика

**Шрифт:** системный — SF Pro (iOS), Roboto (Android). Свои шрифты не подключаем.

**Шкала** (токены `typography` в `src/constants/typography.ts`, через `<Text variant="…">`):

| Вариант | Размер / строка | Вес | Где |
|---|---|---|---|
| `display` 🆕 | 40 / 48 | 700 | крупные цифры: код игры, счёт, результат теста |
| `h1` | 32 / 40 | 700 | заголовок экрана-приветствия, большие итоги |
| `h2` | 24 / 32 | 700 | заголовок экрана (крупный), слово на карточке |
| `h3` | 20 / 28 | 600 | заголовок раздела, заголовок окна |
| `bodyLarge` | 18 / 26 | 400 | лид-абзац, слово в тесте |
| `body` | 16 / 24 | 400 | основной текст, пункты списка |
| `bodySmall` | 14 / 20 | 400 | подписи, описания |
| `caption` | 12 / 16 | 400 | мета-данные, подсказки под полем |
| `label` | 14 / 20 | 600 | кнопки второго уровня, подписи полей |
| `button` | 16 / 24 | 600 | текст кнопок |
| `overline` 🆕 | 12 / 16 | 600, `letterSpacing: 0.8`, ЗАГЛАВНЫЕ | подписи разделов («АККАУНТ», «ОБУЧЕНИЕ») |

**Правила:**
- Размеры **только из шкалы**: 12, 14, 16, 18, 20, 24, 32, 40. Сейчас в коде 27 разных размеров (9–120) — сводим к шкале.
- **Минимум 12 px.** Текст 9–11 px запрещён.
- **Веса только 400, 600, 700.** `500`, `800`, `900` не используем. Жирное (700) — только для заголовков и цифр; если жирное всё, ничего не выделено.
- Если экран меняет `fontSize`, он обязан взять и `lineHeight` из той же строки шкалы (иначе iOS обрезает верх текста).
- ЗАГЛАВНЫЕ — только `overline`. Никаких заголовков капсом.

## 4. Отступы и сетка

Сетка **4 pt**. Токены `spacing`:

| Токен | px | Где |
|---|---|---|
| `xxs` | 4 | между иконкой и текстом в чипе, мелкие зазоры |
| `xs` | 8 | между связанными элементами (подпись ↔ поле) |
| `s` | 12 | внутри компактных элементов, между чипами |
| `m` | 16 | **боковой отступ экрана**, внутренний отступ карточки, между карточками |
| `l` | 24 | между разделами экрана |
| `xl` | 32 | крупные разрывы, верх пустых состояний |
| `xxl` | 48 | нижний запас под плавающую кнопку/нижнюю панель |

**Правила:**
- Боковой отступ экрана — **16** везде (одинаково на всех экранах).
- Между разделами — 24, между карточками внутри раздела — 12.
- Внутри карточки — 16.
- Никаких «на глаз» `marginTop: 6`, `paddingTop: 10` — только токены (допускается `spacing.x / 2` для 2-px выравниваний, осознанно).
- Верхний отступ экрана — полный safe area (без «урезаний»), нижний — safe area + высота панели.

## 5. Скругления

| Токен | px | Где |
|---|---|---|
| `borderRadius.s` | 8 | чипы-метки, маленькие бейджи |
| `borderRadius.m` | 12 | **кнопки, поля ввода**, маленькие карточки |
| `borderRadius.l` | 16 | **карточки**, блоки, строки-плитки |
| `borderRadius.xl` | 24 | всплывающие окна и нижние листы (верхние углы) |

Только эти пять. Сейчас в коде больше 12 разных значений (2, 3, 4, 6, 14, 18, 20, 22…).

## 6. Иконки

- **Везде — `lucide-react-native`.** Единственное исключение — **нижняя панель вкладок** (Главная, Библиотека, Тест, Профиль): там остаются `Ionicons`, как сейчас. Во всех остальных местах Ionicons не используем.
- Размеры — токены `iconSize`: **16** (в тексте, чипах), **20** (кнопки, строки списков), **24** (навигация, шапка), **32** (акцентные блоки), **48** (пустые состояния).
- Толщина линии — по умолчанию (2). Не смешиваем залитые и контурные иконки в одном ряду.
- Цвет — `textSecondary` по умолчанию, `primary` для активного, смысловые — для статусов.
- **Эмодзи в интерфейсе запрещены полностью** — ни в кнопках, ни в статусах, ни в празднованиях, ни в иконках категорий. Вместо эмодзи — иконка lucide (при необходимости в цветном круге `alpha(цвет, 10)`).
  - Категории наборов (сейчас ✈️ 🍽️ 📚 ✏️ 💼 ⭐️ ✨) — показываются иконкой lucide по ключу категории: `general` → `Star`, `travel` → `Plane`, `food` → `UtensilsCrossed`, `study` → `BookOpen`, `work` → `Briefcase`, `grammar` → `PenLine`, `custom` → `Sparkles`.
  - Медали и празднования (🥇 🥈 🥉 🏆 🎯 🔥 💪) — `Medal`, `Trophy`, `Target`, `Flame`, `Dumbbell` в смысловых цветах (`star`, `streak`, `success`).
  - **Исключение — флаги языков** (🇬🇧 🇩🇪 🇷🇺 …) рядом с названием языка: остаются как есть.
  - **Не трогаем** эмодзи внутри пользовательского контента: текст карточек, названия наборов и сообщения, которые написал сам пользователь.
- Кнопка из одной иконки обязана иметь `accessibilityLabel`.

## 7. Компоненты

### 7.1 Кнопки

| Тип | Вид | Где |
|---|---|---|
| **Главная** | заливка `primaryFill`, текст `onPrimary`, `button` 16/600, высота **52**, скругление 12, на всю ширину | одно главное действие на экране |
| **Вторичная** | прозрачная, рамка 1.5 `primary`, текст `primary` | альтернатива главной («Подключиться к курсу») |
| **Тихая** | без фона и рамки, текст `primary` (или `textSecondary`) | «Отмена», «Пропустить», ссылки |
| **Опасная** | текст `errorText`, без заливки; заливка `error` только в окне подтверждения | «Удалить», «Выйти» |
| **Иконка** | круг 44×44 (иконка 20–24), фон `surfaceMuted` | «назад», «ещё», закрыть |

- **Одна главная кнопка на экран** — правило для новых экранов. На существующих экранах количество кнопок не меняем, приводим только их вид к типам выше.
- Минимальная зона нажатия **44×44** (используем `hitSlop`, если визуально меньше).
- Неактивная: прозрачность 0.5, без смены цвета.
- Нажатие: `primaryPressed` или прозрачность 0.85; масштаб 0.98 допустим для главной кнопки.
- Загрузка: спиннер вместо текста, ширина не меняется.

### 7.2 Поля ввода

- Высота 48 (однострочное), скругление 12, рамка 1 `border`, фон `surface` (или `surfaceMuted` для поиска).
- Фокус: рамка `primary`. Ошибка: рамка `error` + текст ошибки `caption` `errorText` под полем.
- Подпись над полем — `label` `textSecondary`, отступ до поля 8.
- Плейсхолдер — `textTertiary`, пример ввода, а не повтор подписи.
- **Клавиатура не открывается сама** — только по нажатию на поле (исключения: поиск, код из 4 цифр).

### 7.3 Карточки и списки

- Карточка: `surface`, скругление 16, рамка 1 `border` **или** мягкая тень — не обе сразу. Отступ внутри 16.
- Строка списка: высота ≥ 52, иконка 20 слева (`textSecondary`), текст `body`, справа шеврон 16 `textTertiary` или переключатель. Разделитель 1 px `border` с отступом 16 слева.
- Группы строк — в одной карточке, над группой `overline`-подпись.

### 7.4 Шапка экрана

- Высота 56, фон `background`, без тени; разделитель снизу 1 px `border` только на экранах со скроллом.
- Слева кнопка «назад» — иконка-кнопка 44×44, `ArrowLeft` 24.
- Заголовок: на вложенных экранах — **по центру, 16/600**; на корневых вкладках (Главная, Библиотека, Профиль) — **слева, `h2`**.
- Одна общая `ScreenHeader`-компонента на всё приложение (сейчас у каждого экрана своя).

### 7.5 Нижняя панель вкладок

- 4 вкладки максимум. Иконки — **`Ionicons`** (исключение из правила lucide, раздел 6), размер 24.
- **Иконка + подпись** под ней: «Главная», «Библиотека», «Тест», «Профиль» (`caption` 12/600). Без подписей понятна только «Главная».
- Активная: `primary`, неактивная: `textTertiary`.

### 7.6 Всплывающие окна и листы

- **Нижний лист** (bottom sheet) — основной формат: `surface`, верхние углы 24, `overlay` под ним, «ручка» сверху 36×4.
- Внизу всегда способ закрыть: «Отмена» / «Пропустить» (тихая кнопка). По фону закрываем только необязательные листы (меню, сортировка), но **не** формы с вводом.
- Одновременно — не больше одного окна. Если сработали два (празднование серии + оценка), второе откладываем.

### 7.7 Сообщения пользователю

| Ситуация | Формат |
|---|---|
| Успех («Сохранено», «Скопировано») | **toast** снизу, 2 с, без кнопок |
| Ошибка, которую можно исправить | прямо у элемента (под полем, в карточке) + «Повторить» |
| Нет сети | баннер сверху экрана |
| Опасное подтверждение (удалить, выйти) | системный `Alert` с кнопкой `destructive` |
| Всё остальное | **не** системный `Alert` |

### 7.8 Состояния экрана

- **Загрузка:** скелетоны (серые блоки формы контента, `surfaceMuted`, мягкое мерцание). Спиннер — только внутри кнопки и для действий < 1 с.
- **Пусто:** иконка 48 в круге `primary + '1A'` → заголовок `h3` → одно предложение `bodySmall` `textSecondary` → главная кнопка (+ вторичная при необходимости). Пустое состояние всегда говорит, **что сделать дальше**.
- **Ошибка загрузки:** иконка, «Не удалось загрузить», кнопка «Повторить». Не показывать технический текст.

### 7.9 Прогресс и геймификация

- Полоса прогресса: высота 8, скругление `full`, фон `surfaceMuted`, заливка `primary` (или смысловой цвет).
- Серия — всегда огонь + `streak`; алмазы — ромб + `diamond`. Одна валюта — один цвет и одна иконка везде.
- Празднования — полноэкранные/лист с **иконкой lucide** (не эмодзи) и лёгкой вибрацией, не чаще одного окна за раз.

## 8. Движение и отклик

- Длительности — токены `animation`: 150 (нажатия, переключатели), 250 (появление элементов, переходы), 400 (празднования).
- Переходы между экранами — системные (справа налево на iOS).
- Вибрация (`triggerHaptic`) с учётом настройки «Вибрация»:
  - `selection` — выбор варианта, переключение, вкладки;
  - `notificationSuccess` — правильный ответ, успешная отправка;
  - `notificationError` — неверный ответ;
  - не вибрируем на прокрутке и частых повторяющихся действиях.
- Звуки — только ответы в тренировках, с учётом настройки «Звуки».

## 9. Тексты и тон

- **Только русский** в интерфейсе. Английский допустим только в названии «Flashly» и в пользовательском контенте (слова в наборах). Никаких «Test Lobby», «Join Now», «Retry».
- **Обращение на «ты»** — везде, одинаково: интерфейс, окна, ошибки, пуш-уведомления («Выбери ответ», «Создай набор», «Проверь интернет», «Ты на 2-м месте»).
- **Никаких выдуманных данных** на экранах: всё, что видит пользователь, — его настоящие данные. Заглушки с придуманными числами, датами и именами не показываем.
- Коротко: кнопка — 1–3 слова, глагол в начале («Создать набор», «Начать тест»).
- Ошибка = что случилось + что сделать: «Не удалось сохранить. Проверь интернет и попробуй ещё раз».
- Не больше одного «!» на экран. Хвалим конкретно («+12 слов за неделю»), а не абстрактно.
- Числа — с правильными окончаниями (1 слово, 2 слова, 5 слов).

**Словарь** (один термин — одно понятие):

| Говорим | Не говорим |
|---|---|
| набор | колода, сет, деск |
| карточка | флешкарта |
| курс | класс, группа |
| тест | квиз, опрос |
| серия | стрик |
| алмазы | кристаллы, гемы |
| повторение дня | ежедневка |
| учитель / ученик | преподаватель / студент (в интерфейсе) |

## 10. Тёмная тема

- Только через токены: экраны **не** содержат `isDark ? '#…' : '#…'`. Если нужен цвет, отличающийся по теме, — это новый токен в `colors.ts`.
- Поверхности сплошные (см. 2.3), тени в тёмной теме не используются — отделяем рамкой `border`.
- Проверять каждый новый экран в обеих темах.

---

## 11. Доступность

- Контраст текста ≥ **4,5:1** (крупный текст ≥ 18 px жирный и иконки — ≥ 3:1). Все пары в разделе 2 проверены.
- Зона нажатия ≥ 44×44.
- Каждая кнопка без текста — `accessibilityLabel`; переключатели и выбор — `accessibilityRole` и состояние.
- Не передаём смысл только цветом: правильный/неверный ответ = цвет **и** иконка (✓ / ✕).
- Минимальный размер текста 12 px, системное увеличение шрифта не должно ломать вёрстку.

---

## 12. Чек-лист перед мержем экрана

- [ ] Ни одного `'#…'`, `rgba(…)` и `isDark ? …` в экране — только токены
- [ ] Размеры шрифта только из шкалы, ≥ 12, веса 400/600/700
- [ ] Отступы и скругления только из токенов, боковой отступ 16
- [ ] Иконки только lucide (кроме панели вкладок), размеры из `iconSize`, ни одного эмодзи в интерфейсе
- [ ] Кнопки — типы из раздела 7.1, зоны нажатия ≥ 44 (новый экран — одна главная кнопка)
- [ ] Все тексты на русском, на «ты», термины из словаря; нет выдуманных данных
- [ ] Есть состояния: загрузка (скелетон), пусто (с действием), ошибка (с «Повторить»)
- [ ] Успех — toast, а не `Alert`
- [ ] Проверено в светлой и тёмной теме
- [ ] У иконок-кнопок есть `accessibilityLabel`

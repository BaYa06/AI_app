# Возврат библиотеки: наборы публикует только команда

Библиотеку отключили в `Review 1.2` (коммит 18f452e): чужие наборы без модерации — отказ по правилу 1.2 (User-Generated Content).

Решение (13.10.2026): включаем библиотеку, но публиковать наборы могут только админы (`users.is_admin`). Весь контент библиотеки — от команды, как каталог учебников, поэтому требования 1.2 к пользовательскому контенту не применяются. Автор в карточках набора — «Flashly».

## Правила

- Один шаг = один коммит, в сообщении — `Library N: …`.
- Совместимость API (`plan/new/release_safety.md`, Release 2): миграций нет, ответы только расширяются. Сервер выкладывается раньше сборки.
- Старые версии приложения (до отключения) с формой публикации получат 403 у не-админа и увидят в библиотеке только наборы команды — это безопасно.

## Шаги

- [x] **Library 1. Сервер: публикует только админ.** `api/library.js`.
  - Публикация и обновление публикации — только `is_admin`, иначе 403 `admins_only`. Снять свою публикацию по-прежнему может любой автор.
  - Список, детали, карточки, импорт — только наборы админов; старые публикации обычных пользователей не показываются (не удаляются). `author_name` = «Flashly».
  - `check-published` дополнительно отдаёт `canPublish`; новое действие `can-publish`.
  - Переменная `COMMUNITY_LIBRARY_ENABLED` в Vercel больше не нужна.
- [x] **Library 2. Приложение: включить библиотеку.** `src/config/features.ts` → `true`.
  - Блок «Библиотека» в редакторе набора и «Мои публикации» в профиле — только если `canPublish`.
  - Остальным: просмотр, импорт, лайки, оценки, «Пожаловаться».
- [x] **Library 3. Условия и политика.** `public/terms.html`, `public/privacy.html`: библиотека — наборы, подобранные командой Flashly; пользователи их не публикуют.
- [ ] **Library 4. Отправка (вручную).**
  - Выложить сервер на Vercel до отправки сборки.
  - Опубликовать несколько наборов админским аккаунтом, чтобы библиотека не была пустой у рецензента.
  - Review Notes — заменить фразу о UGC:
    > The Library tab contains only flashcard sets curated and published by our team (like the textbook catalog). Regular users cannot publish content visible to other users; courses are private and invite-only. Users can report any set via the "…" menu or Profile → Contact us.
  - Age Rating не меняется.

## Проверка в TestFlight

1. Обычный аккаунт: в редакторе набора нет блока «Библиотека», в профиле нет «Мои публикации»; библиотека показывает наборы, автор — «Flashly»; импорт работает.
2. Админ: блок публикации есть, набор публикуется и виден другим.

## На потом: публикация для всех

Если захотим открыть публикацию пользователям — нужна модерация по 1.2: премодерация в админке, фильтр слов, жалоба скрывает набор у пожаловавшегося и уходит в очередь (ответ в течение 24 часов), «Заблокировать автора» + список в профиле, запрет публикаций автору, согласие с условиями (нулевая терпимость) перед первой публикацией, раздел в `terms.html`, отметка UGC в Age Rating.

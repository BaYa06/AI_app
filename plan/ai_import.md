# ИИ-импорт: бесплатный Gemini и единый экран «Создать карточки»

## Почему

Онлайн-генерация не работает: все ИИ-функции идут через Vertex AI (`@google-cloud/vertexai`,
`VERTEX_SA_KEY`), а у Vertex нет бесплатного уровня. Затронуто:

- `api/_ai/*` (Vercel): `translate-words`, `generate-examples`, `context` (дистракторы), `extract-image`, `extract-pdf`;
- `server/import-files.js` — отдельная VM на GCP `http://34.9.20.41:3001` (HTTP без шифрования), с неё работает экран «Создать из файлов».

Заодно в приложении две разные страницы для одной задачи:

| | Модалка «Импорт» (SetDetailScreen) | «Создать из файлов» (ImportFilesScreen) |
|---|---|---|
| Источники | PDF, TSV; кнопка фото скрыта (`display: 'none'`) | камера, галерея, PDF/CSV/TSV, до 5 файлов |
| Инструкция для ИИ | нет | есть + быстрые подсказки |
| Примеры предложений | да | нет |
| Веб | да | нет |
| Сервер | Vercel `/api/ai` | GCP VM |

Найденные баги: больше 100 слов → у остальных молча нет примеров (`slice(0, 100)`); в подсказке
«PDF до 10 МБ», а код пускает 4 МБ; ошибка ИИ при примерах молча глотается; в PDF не передаются
языки набора; в предпросмотре нельзя править, снимать слова, нет проверки дублей; «Отмена» и
закрытие теряют уже распознанное; все ошибки — одна фраза «попробуй ещё раз».
Сплошной текст: модалка вернёт мусор или «не нашли слов», а «Создать из файлов» молча сделает
вопрос-ответ (`server/import-files.js:106`).

## Решения (13.10.2026)

- **Провайдер — только Gemini через Google AI Studio** (ключ `GEMINI_API_KEY`, бесплатный уровень).
  Резервные провайдеры (Groq, Mistral, Vercel AI Gateway) — не в этом плане.
  Лимиты бесплатного уровня (по сторонним данным, точные — в AI Studio → Rate limits):
  Gemini 3 Flash ~10 в минуту / ~1500 в день, 3.1 Flash-Lite ~15 / ~1000. Квота общая на проект
  (на всех пользователей), у каждой модели своя. Данные бесплатного уровня Google может
  использовать для обучения; в ЕС/UK/Швейцарии бесплатный уровень для конечных пользователей запрещён.
- **Модели:** фото/PDF/импорт — Gemini 3 Flash; перевод, примеры, дистракторы — Flash-Lite.
  Размышления модели (`thinking`) — минимум: иначе ответы в 2–3 раза дольше.
- **GCP VM переносим на Vercel**, `import-files` становится `api/ai?fn=import-files`.
- **Лимит — 20 распознаваний на пользователя в день.** Считаются только распознавания
  (фото, PDF, вставленный текст); перевод, примеры и дистракторы не считаются.
- **Единый экран — вариант A** («Плитки источников»). Макеты: https://claude.ai/artifact/4kEZqKZRtHwbSGe1ZXMGJN
- **Кнопка в приложении — «Из фото или файла»** (не «ИИ», не «Импорт»), значок ✨ — признак ИИ.
  Три входа: шапка списка карточек в наборе, лист «Новая карточка», пустой набор.
- Озвучка (Google Cloud TTS в `src/utils/speech.ts`) — отдельным планом.

## Поток экранов

```
A. Старт ── «Примеры →» ──► Что понимает ИИ (справка)
  │
  ├─ CSV/TSV ─────────────────────────────────────► 3б
  ▼
2. Обработка ── ИИ вернул kind / lang ──┐
  ├─ vocab (словарь, список) ───────────────────────► 3б. Проверка
  ├─ text (сплошной текст) ──► 3a. Что сделать? ──► 2 ──► 3б
  ├─ другой язык ──────────► Предупреждение: язык ───────► 3б
  ├─ empty / exercise ─────► Слов не найдено ──► A
  └─ 429 / лимит ──────────► ИИ перегружен ──► автоповтор ──► 2
3б ── «Добавить N» (+ примеры, снова шаг 2) ──► 4. Итог
```

## Правила

- Один шаг = один коммит, в сообщении — `AI N: …`.
- Совместимость API (`plan/release_safety.md`, Release 2): старые адреса и форматы ответов
  (`/api/extract-image`, `/api/extract-pdf`, `/api/generate-examples`, `/api/translate-words`,
  `/api/context`) остаются; ответы только расширяются новыми полями. Миграции только добавляют.
- Старые клиенты не шлют токен → для них лимит на пользователя не действует (только общий лимит Google).
- Сервер выкладывается раньше сборки. Проверять сначала на `dev` (Preview + ветка Neon `staging`).
- Тексты ошибок — на русском и по делу: что случилось и что сделать.

## Шаги

### Сервер

- [x] **AI 1. Vertex → Gemini AI Studio.** `api/_ai/*`, `package.json`, `public/privacy.html`, `src/services/aiConsent.ts`.
  - Выяснилось: `gemini-2.0-flash` (старая модель по умолчанию) Google отключил — с оплатой тоже бы не работало.
  - Общий модуль `api/_ai/gemini.js`: клиент `@google/genai` по `GEMINI_API_KEY`; модель из
    `GEMINI_MODEL_VISION` / `GEMINI_MODEL_TEXT` (дефолты — алиасы `gemini-flash-latest` /
    `gemini-flash-lite-latest`, Google сам переводит их на актуальные версии);
    `thinkingLevel: LOW`; ответ в JSON (`responseMimeType: 'application/json'`), разбор с
    запасным `match(/\[[\s\S]*\]/)` как раньше; тайм-аут запроса 50 с.
  - Окно согласия: честный текст (Google может использовать данные для улучшения моделей),
    ключ `ai_consent_granted_v2` — новая версия спросит заново. Старые сборки показывают старый
    текст, пока не обновятся.
  - `@google-cloud/vertexai` остаётся в `package.json`, пока жив `server/import-files.js` (AI 9).
  - **Замеры на бесплатном ключе (13.10.2026, Preview + локально):** `gemini-2.5-*` отключены (404);
    самые новые (`3.7`, `3.8`, `*-latest`) почти всегда 503 «перегружена»; рабочие — `3.6-flash`,
    `3-flash-preview`, `3.5-flash` (быстрые, но бывают 503/429 и зависания) и `3.1-flash-lite`
    (медленнее, 3–14 с, почти не отказывает). Поэтому у каждой задачи цепочка моделей: 503/429/зависание
    → следующая модель; на попытку ≤ 35 с, всего ≤ 90 с; всё перегружено → `429 ai_busy`.
    Первой везде стоит 3.1-flash-lite (решение 13.10: стабильность и одинаковое качество важнее скорости).
    Фото: 3.1-flash-lite → 3.6-flash → 3-flash-preview → 3.5-flash. Текст: 3.1-flash-lite → 3.6-flash → 3-flash-preview.
    Порядок меняется env `GEMINI_MODEL_VISION` / `GEMINI_MODEL_TEXT` (через запятую) без кода.
  - Проверено: словарь на фото — 5/5 слов; сплошной текст → `kind: text` без карточек; список без
    перевода — переведён сразу; вопрос-ответ по тексту — 6 вопросов. Бесплатный уровень хрупкий:
    поминутный лимит модели кончается за несколько запросов подряд — приложению нужен
    понятный «ИИ перегружен» с автоповтором (AI 5).
  - Ошибка 429 от Google → наш ответ `429 { error: 'ai_busy', retryAfter }`; тайм-аут → `504 { error: 'ai_timeout' }`.
  - Все 5 обработчиков переходят на модуль; промпты и форматы ответов не меняются.
  - `extract-pdf` принимает необязательные `languageFrom` / `languageTo`, как фото.
  - `vercel.json`: `api/ai.js` `maxDuration` 60 → 300 (Fluid compute включён). Регион функций — `iad1` (США).
  - `privacy.html`: «Google Cloud: Gemini (Vertex AI)» → «Google: Gemini API»; упомянуть, что
    бесплатный уровень Google может использовать данные для улучшения моделей.
  - Вручную: создать ключ в AI Studio, добавить `GEMINI_API_KEY` в Vercel (Preview и Production),
    посмотреть реальные лимиты в AI Studio → Rate limits и записать их сюда.
- [x] **AI 2. `import-files` на Vercel + определение типа содержимого.** `api/_ai/import-files.js`, `api/ai.js`, `vercel.json`.
  - `fn=import-files` (и `/api/import-files`): до 5 файлов — фото (JPG, PNG, WebP, HEIC), PDF, CSV/TSV и новый `text/plain` (вставленный текст).
  - Тело запроса Vercel — максимум 4,5 МБ (на VM было 20 МБ): всё вместе до ~3 МБ, иначе `413 too_large`.
    Клиент сжимает фото; PDF — до 3 МБ.
  - Ответ: `cards` (+ необязательные `example`, `confidence: 'low'`), `suggestedTitle`, `count`,
    `kind: 'vocab' | 'text' | 'exercise' | 'empty'`, `lang` (ISO 639-1), `excerpt` при `kind: 'text'`.
  - Молчаливого перехода в вопрос-ответ больше нет: при `goal: 'vocab'` без своей инструкции
    текст/упражнение/пусто → пустой `cards` и `kind` — приложение спрашивает, что делать.
  - `goal`: `vocab` (по умолчанию; нет перевода — переводит сразу, без отдельного запроса) |
    `pick_words` (+ `level` A1–C1, ~15 слов, пример — предложение из текста) | `all_words` | `terms` | `qa`.
    Своя инструкция `prompt` (до 500 символов) важнее `goal`.
  - `extract-image` / `extract-pdf` не трогаем: новый экран ходит только в `import-files`, старые — для старых версий.

- [x] **AI 3. Лимит 20 распознаваний в день.** `api/_ai/usage.js`, `api/_ai/import-files.js`, `api/ai.js`.
  - Без новой таблицы и миграции: счётчик в существующей `api_rate_limits` (общая с test/teacher,
    уже чистится при удалении аккаунта), `action = 'ai-recognize'`, окно — сутки по UTC.
    Списание атомарное (`ON CONFLICT … DO UPDATE … WHERE attempts < limit`), проверено на Postgres.
  - `import-files` требует Bearer-токен (у гостей — анонимный пользователь Supabase) → иначе 401.
    Старых клиентов у этого адреса нет, поэтому совместимость не страдает.
  - Превышение → `429 { error: 'daily_limit', limit, resetAt }`. Распознавание возвращается, если ИИ
    упал или не нашёл ни одной карточки (текст/упражнение/пусто — следующим запросом выберут цель).
  - `fn=usage` → `{ used, limit, resetAt }`; то же `usage` в ответе `import-files`.
  - `extract-image` / `extract-pdf` не считаются: их зовут только старые клиенты, без токена.
  - Лимит меняется env `AI_DAILY_LIMIT` (по умолчанию 20).

- [x] **AI 3.1. Промпты под наши задачи и языки.** `api/_ai/prompts.js` + все функции; клиент: `ApiService`, `ContextFillScreen`, `distractors.ts`.
  - Языки приходят кодами (`de`, `tr`, `zh`…) — в промпт идут названия (`Intl.DisplayNames`).
  - Общие правила формата слова и перевода (артикли, заметки «der Hund, -e», возвратные глаголы,
    CJK-письмо; перевод — инфинитив/им. падеж, артикли в немецком/французском… переводе) и
    распознавания словаря (обратный порядок столбцов, перевод на третий язык → переводим в язык набора).
  - Примеры — под «Слово в контексте»: `wordForm` с артиклем, если он есть в карточке; грамматика
    важнее «фразы целиком»; сервер обнуляет `wordForm`, которого нет в предложении.
    Новые необязательные `languageFrom/To` (старые клиенты — язык определяется сам).
  - Дистракторы — в той же форме, что и слово; новое необязательное `example` — не подходят в пропуск.
  - `import-files`: «незнакомые слова» сразу с `example`/`wordForm`/`wordType`; термины и вопросы — для любого предмета.
  - Проверено: DE/EN/TR/ZH/JA/KO, RU→DE, немецко-английский учебник в наборе DE→RU, перевёрнутый список.
